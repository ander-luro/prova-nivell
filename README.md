# Prova de Nivell: Colla Castellera

## Descripción del Ejercicio
El ejercicio consiste en diseñar un sistema en PHP POO para modelar una colla castellera y su catálogo de castells

## Requisitos del Ejercicio
Cada Colla tiene la siguiente información:
- Cantidad de personas activas
- Castells que esa colla es capaz de montar

De cada Castell se debe especificar:
- Número de personas por piso
- Cantidad total de pisos
- Si tiene folre
- Si tiene manilles

Funcionalidades requeridas:
- Dado un numero, mostrar los castells que tengan un número de pisos mayor o igual a ese.
- Los castells que tienen folre

## Requisitos Técnicos
- PHP
